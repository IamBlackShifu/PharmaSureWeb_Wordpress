🚀 QUICK START (Choose Your Path)
═══════════════════════════════════════════════════════════════════════════════

PATH 1: WINDOWS (FASTEST - 5 MINUTES)
──────────────────────────────────────────────────────────────────────────────

  1. Open PowerShell as Administrator
  
  2. Install prerequisites:
     choco install php@8.2 mysql@8.0 composer -y
  
  3. Create database:
     mysql -u root -e @"
     CREATE DATABASE pharmasure_db CHARACTER SET utf8mb4;
     CREATE USER 'pharmasure'@'localhost' IDENTIFIED BY 'pharmasure_pass';
     GRANT ALL PRIVILEGES ON pharmasure_db.* TO 'pharmasure'@'localhost';
     FLUSH PRIVILEGES;
     "@
  
  4. Install PharmaSure:
     cd pharmasure-wordpress
     php setup.php install
  
  5. Start server:
     php -S localhost:8080
  
  6. Test:
     php scripts/test-isolation.php
     php scripts/test-license.php
  
  7. Access admin:
     http://localhost:8080/wp-admin
     Login: admin / admin123

  → Full guide: WINDOWS-QUICKSTART.md


PATH 2: MAC/LINUX (5 MINUTES)
──────────────────────────────────────────────────────────────────────────────

  1. Install prerequisites (Ubuntu/Debian):
     sudo apt-get update
     sudo apt-get install php8.2-cli php8.2-mysql php8.2-gd php8.2-zip \
       php8.2-bcmath php8.2-intl mysql-server composer
  
  2-7: Same as Windows above
  
  → Full guide: LOCAL-SETUP.md


PATH 3: DOCKER (IF NO PREREQUISITES)
──────────────────────────────────────────────────────────────────────────────

  docker-compose up -d
  # Wait 30 seconds for MySQL
  docker-compose exec -T wpcli wp core install \
    --url=http://localhost:8080 \
    --title="PharmaSure" \
    --admin_user=admin \
    --admin_password=admin123 \
    --admin_email=admin@pharmasure.local \
    --skip-email
  
  Access: http://localhost:8080/wp-admin
