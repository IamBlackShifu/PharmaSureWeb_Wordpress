## 📞 Support During Testing

### Common Issues

**"PHP not recognized"**
→ See WINDOWS-QUICKSTART.md - PHP Installation section

**"MySQL connection failed"**
→ Verify MySQL running: `mysql -u root -e "SELECT 1;"`

**"WordPress not installing"**
→ Check .env variables match database settings

**"Tests failing"**
→ Check debug.log: `tail -50 wp-content/debug.log`

**"Plugins not loading"**
→ Run: `wp plugin list` to see status

### Contact Points
- Check error logs: `wp-content/debug.log`
- Check PHP error: `php -l setup.php`
- Check MySQL: `mysql -u pharmasure -ppharmasure_pass pharmasure_db -e "SELECT 1;"`
- Check WordPress: `wp core version`
