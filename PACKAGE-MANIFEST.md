## 🚀 Getting Started

### For Immediate Testing (5 minutes)

**Windows:**
```powershell
# See: WINDOWS-QUICKSTART.md
choco install php@8.2 mysql@8.0 composer -y
mysql -u root -e "CREATE DATABASE pharmasure_db; CREATE USER 'pharmasure' IDENTIFIED BY 'pharmasure_pass'; GRANT ALL ON pharmasure_db.* TO 'pharmasure';"
git clone <repo> && cd pharmasure-wordpress
php setup.php install
php -S localhost:8080
# Open: http://localhost:8080/wp-admin (admin/admin123)
```

**macOS/Linux:**
```bash
# See: LOCAL-SETUP.md
brew install php@8.2 mysql composer git  # or apt-get for Ubuntu
mysql -u root -e "CREATE DATABASE pharmasure_db; ..."
git clone <repo> && cd pharmasure-wordpress
php setup.php install
php -S localhost:8080
```

**Docker (if no prerequisites):**
```bash
docker-compose up -d
# Wait 30 seconds for MySQL
docker-compose exec -T wpcli wp core install ...
```

### Test Everything

```bash
# Check system
php setup.php check

# Run tests
php scripts/test-isolation.php
php scripts/test-license.php

# Access admin
# http://localhost:8080/wp-admin
```

## 🔐 Security Guarantees

### Tenant Isolation
✅ **Cannot be guessed** - Tenant derived from authenticated user (server-side)  
✅ **Cannot be overridden** - Immutable per-request context  
✅ **Database enforced** - Every query includes WHERE tenant_id = X  
✅ **Cross-tenant prevented** - Composite unique keys at database level  
✅ **No data leakage** - Failed queries return zero rows, not errors  
✅ **Auditable** - Correlation IDs link all operations  

### License Security
✅ **Cannot be forged** - RS256 cryptographic signing (private key server-only)  
✅ **Cannot be modified** - Signature verification on every operation  
✅ **Replay prevented** - Token revocation list  
✅ **Offline supported** - Limited 7-day grace period (configurable)  
✅ **Server authoritative** - Database is source of truth  
✅ **Auditable** - All token issuances logged  

### Data Security
✅ **Proper types** - Money as integer cents (no float precision loss)  
✅ **Proper encoding** - UTF-8MB4 for international characters  
✅ **Constraints enforced** - Foreign keys prevent orphaned records  
✅ **Audit trail** - Immutable append-only event log  
✅ **Sensitive redacted** - PII excluded from audit logs  
✅ **Environment protected** - Secrets in .env, not code
