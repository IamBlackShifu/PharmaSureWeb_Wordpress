🚀 RIGHT NOW - 5 MINUTE SETUP
═══════════════════════════════════════════════════════════════════════════════

Step 1: Install Prerequisites (2 minutes)
  
  Windows (PowerShell as Admin):
    choco install php@8.2 mysql@8.0 composer -y
  
  Mac (Homebrew):
    brew install php@8.2 mysql@latest composer
  
  Ubuntu/Debian:
    sudo apt-get install php8.2-cli php8.2-mysql php8.2-gd \
      php8.2-zip php8.2-bcmath php8.2-intl mysql-server composer

Step 2: Create Database (1 minute)
  
  mysql -u root -e @"
  CREATE DATABASE pharmasure_db CHARACTER SET utf8mb4;
  CREATE USER 'pharmasure'@'localhost' IDENTIFIED BY 'pharmasure_pass';
  GRANT ALL PRIVILEGES ON pharmasure_db.* TO 'pharmasure'@'localhost';
  FLUSH PRIVILEGES;
  "@

Step 3: Install PharmaSure (1 minute)
  
  cd pharmasure-wordpress
  php setup.php install
  
  You'll see:
    ✓ WordPress installed
    ✓ Multisite enabled
    ✓ pharmasure-core plugin activated

Step 4: Start & Access (1 minute)
  
  php -S localhost:8080
  
  Browser: http://localhost:8080/wp-admin
  Login: admin / admin123

DONE! ✅
