│  │    ├─ Verify RSA signature                      │                       │
│  │    └─ Check revocation list                     │                       │
│  │ → Return: [entitlements, quotas, offline_grace] │                       │
│  │ → If invalid: return WP_Error (stable code)    │                       │

│  ✅ Signature validation on EVERY offline operation                       │

│  ✅ Audit log tracks all token issuances                                  │

│  ✅ active      → Full access                                             │
